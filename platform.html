Reference interface. Production base URL, credentials, availability and tenant scopes are provided only under an executed agreement. Public verification does not require an API key.

SECURITY MODEL

Keys are not the root of trust

API credentials control who may submit. Public SHA-256 commitments and time anchors control whether a published record can be independently checked.

A leaked key must never permit silent history rewriting. Revocation and version changes are new events.
